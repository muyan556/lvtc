# 六安职业技术学院 · 拾光课程表适配器 v1

## 文件

- `adapters.yaml`：拾光适配器配置
- `lvtc.js`：课表解析脚本

## 使用

1. 通过六安职业技术学院统一信息门户完成登录。
2. 进入强智教务系统。
3. 打开“个人课表信息”页面，并确认目标学期已经显示。
4. 在拾光课程表中点击“执行导入”。
5. 第一次点击如果仍停留在门户页面，脚本会尝试打开教务系统；进入课表页后再次点击“执行导入”。

## v1 解析规则

脚本针对实际抓包中的强智 DOM：

- `table.qz-weeklyTable`
- `td[name="kbDataTd"]`
- `ul[name="kbdataUl"] > li.courselists-item`
- `.qz-hasCourse-title`
- `.qz-hasCourse-abbrinfo`

从课程详情中解析：

- 课程名
- 教师
- 教室
- 星期
- 周次
- 起始节次
- 结束节次
- 课程号（作为备注）

`rowspan` 会通过网格计算处理，因此不会简单依赖 DOM 中第几个 `td`。

## 认证

v1 不保存账号、密码、Cookie 或 CAS Ticket。

认证由拾光 WebView 中的学校门户/教务系统完成；脚本只读取当前已经登录的课表页面 DOM。

## 已知限制

1. 尚未自动选择学期；使用当前页面已经选择的学期。
2. 尚未自动写入学期开始日期和学校节次时间表。
3. 如果学校门户中的“教务系统”链接 DOM 发生变化，自动导航可能失效，此时手动进入教务课表页面即可。
4. 本版本优先针对抓包中 `qz-weeklyTable` 结构实现。

## 测试建议

优先使用拾光开发者版本 + 自定义仓库进行测试。

正式提交适配仓库前，应补充 `root_index.yaml` 中的学校条目，并在真实校园网环境测试统一认证、课表解析和导入。
